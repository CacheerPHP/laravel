# Security policy

Security fixes are provided for the latest release in the 1.x series.

Please report suspected vulnerabilities privately to gasparsilvio7@gmail.com.
Include the affected package versions, a description of the impact, and steps
or a minimal example that reproduces the issue. Do not include application
credentials, encryption keys, or production cache contents.

Please avoid disclosing a vulnerability in a public issue until a fix is
available and we have coordinated disclosure.
