# CacheerPHP for Laravel

## About CacheerPHP for Laravel

CacheerPHP for Laravel brings [CacheerPHP](https://github.com/CacheerPHP/CacheerPHP)
storage to Laravel's cache system. Keep using `Cache::` and Laravel's cache-backed
features while choosing the storage and failover your application needs.

- [File, database, Redis, and in-memory backends](https://cacheerphp.com/docs/v6/en/laravel/configuration/).
- [Locks, unique jobs, scheduling, and rate limiting](https://cacheerphp.com/docs/v6/en/laravel/framework-features/).
- [Failover, tiered caching, and encryption](https://cacheerphp.com/docs/v6/en/laravel/configuration/).
